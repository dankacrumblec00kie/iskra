# User Stories и техническое задание

> Составлено AI-агентом (Claude Code) по требованиям курса и описанию идеи. В последнем столбце — чем проверена
> история: «e2e» — сценарий в браузере, «e2e (API)» — запросы к API из тех же тестов (`tests/e2e`).

## Роли

- **Гость** — не вошёл в аккаунт.
- **Пользователь** — вошёл и заполнил анкету.
- **Подписчик** — пользователь с активным Premium.
- **Модератор** — пользователь с ролью `admin`.

## Функциональные требования

### Frontend
- Экраны: главная, вход, регистрация, анкета-мастер, лента, «Рядом», «Лайки», чаты, диалог, чужая анкета, профиль,
  редактирование, Premium, оплата, настройки, уведомления, модерация, правила, конфиденциальность.
- Адаптивность: телефон — нижняя панель вкладок, десктоп — боковое меню.
- У каждого экрана с данными три состояния: загрузка (скелетон), ошибка с кнопкой «Повторить», пустой список с подсказкой.
- Формы проверяются в браузере теми же правилами, что и на сервере (общие схемы Zod).

### Backend
- PostgreSQL, 15 связанных таблиц (см. `docs/03-architecture.md`).
- REST API с CRUD: анкета, фото, свайпы, пары, сообщения, блокировки, жалобы, платежи, уведомления.
- Аутентификация: e-mail и пароль, сессия в httpOnly-cookie; дополнительно OAuth2 через Google.
- Валидация всех входных данных на сервере, единый формат ошибок.

## Нефункциональные требования

- **Безопасность:** хэш пароля scrypt; в базе только хэш токена сессии; защита от CSRF; ограничение частоты запросов;
  проверка прав на каждый объект; координаты и e-mail не попадают в ответы API. Подробно — `docs/05-security-audit.md`.
- **Приватность:** расстояние округляется до километра; из фото удаляются метаданные; анкету можно скрыть и удалить.
- **Возраст:** строго 18+, проверка в форме, на сервере и ограничением в базе данных.
- **Доступность:** семантические роли, подписи у кнопок-иконок, видимый фокус, учёт `prefers-reduced-motion`.

## Вне рамок этой версии

Подтверждение e-mail и восстановление пароля, модерация фотографий, проверка личности, обмен фото в чате,
WebSocket-соединение (сейчас чат обновляется опросом раз в 2,5 секунды), мобильные приложения.
