## Сценарий демо (3–4 минуты)

Подготовка: открыть сайт в двух окнах. Заранее убедиться, что демо-аккаунт на месте (`npm run db:seed` сбрасывает его в исходное состояние).

1. **Главная → регистрация.** Показать ошибку валидации (короткий пароль), затем зарегистрироваться.
2. **Анкета.** Ввести дату младше 18 — отказ. Дальше: пол, «показывать мне», город (подсказки — внешний API), фото.
3. **Лента.** Смахнуть карточку влево, открыть анкету кнопкой «i», поставить лайк тому, кто «Вы понравились» — экран «Это взаимно!».
4. **Чат.** Написать сообщение, дождаться ответа демо-анкеты. Сказать вслух: это демо-режим, анкеты из сида отвечают сами.
5. **Рядом.** Поиск «кофе», фильтр по возрасту.
6. **Лайки.** Размытые превью → **Premium** → тестовая касса → список открыт.
7. **Второе окно — администратор** (`admin@iskra.app`): показатели и очередь жалоб.
8. **Телефон.** Сузить окно браузера: нижняя навигация, тот же функционал.

## Вероятные вопросы

| Вопрос | Ответ |
| --- | --- |
| Почему не Supabase? | Хотелось показать собственный backend: схему, миграции, аутентификацию, права доступа. Supabase скрыл бы эту работу |
| Почему чат на опросе, а не на WebSocket? | Vercel — serverless, постоянных соединений там нет. Опрос раз в 2,5 с прост и надёжен; для роста — отдельный realtime-сервис |
| Как защищены данные о местоположении? | Координаты округляются при сохранении, в API уходит только расстояние в целых километрах, ближе километра — «рядом» |
| Что из дополнительных функций реально работает? | Проверены поиск и фильтры, загрузка фото, геокодинг, тестовая касса, лента уведомлений. ЮKassa, Google и push написаны, но без ключей не запускались |
| Что сделал AI, а что вы? | Код, тесты и документы написал AI-агент по одному запросу. Моя часть — постановка задачи, требования, проверка результата, деплой |
| Что в коде AI пришлось исправлять? | См. таблицу проблем: устаревший API фреймворка, проверка прав при свайпе, ошибки во вспомогательных скриптах |
| Можно ли на этом заработать? | Модель — подписка и буст. Для запуска нужны юрлицо, договор с платёжным сервисом, модерация и маркетинг |
